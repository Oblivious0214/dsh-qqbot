# QQ Bot 0.45.0

本版修复快捷回复选项的设置加载：最新回复会自行读取会话设置，不再依赖输入栏监视器先完成加载；设置轮询失败时保留上次读取的开关状态，恢复连接后继续同步。用户已关闭选项时保持关闭。

生图暂不接入：正式插件不加载绘图服务、绘图工具、相关提示词和界面入口。日语翻译与 Irodori 接入尚未实现，本版不包含这些功能。

保留角色动态设定、全局预设、自定义动作、语音和已有 QQ 聊天功能。标准会话不增加 QQ 专用工具或界面。

验证：1375 项模拟及离线测试通过，1 项跳过；两端类型检查与干净构建通过。未调用真实模型、生图服务、QQ 平台或实体设备；未安装到运行中的本机 DSH。

安装后按 DSH 提示完整退出并重新打开。已有会话在回复完成且分段显示完毕后，显示最新回复的三条快捷选项。
