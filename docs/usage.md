# dsh-qqbot

在 DeepSeek Harness（DSH）里做 QQ 聊天式角色扮演。插件注册一个独立的 `qqbot` Agent 预设，所有提示词、界面和压缩都只在这个预设的会话里生效；关闭或卸载插件后，DSH 和没装过一样。

当前是 **0.37.0 单包合并版**：有预设、提示词槽位、入口、提示词查看器、角色库、`/role` 命令、角色和通用提示词编辑器、分段回复、表情规则、中文摘要模板、QQ 界面和语音条。

### 动作库与三档动作池

所有动作都是动作库里的 `.funscript` 轨迹，程序不再另外生成基础动作。内置 29 套：原基础动作稳定节奏、温柔正弦、渐快、渐慢、间歇、快去慢回、慢去快回、滑动，加上旧版内置的其余 21 套。QQ Bot 设置 → **联动设备** → **动作细调**：先设行程分界和快慢定义，再点绿／黄／红的慢速／中速／高速预设按钮，用轨迹卡片勾选该档动作；点击轨迹图可放大查看。已选卡片直接显示少／普通／多和按权重计算的自动抽取比例。默认快慢分界 150／300（慢速 1–149、中速 150–299、高速 300 起）；慢速池偏舒缓（温柔正弦、呼吸起伏为多），中速池以稳定节奏为多，高速池偏激烈（稳定节奏、强拍律动为多）。高潮没另设动作时用高速池，温存用慢速池。每档至少保留一个动作。名称 `auto` 保留给自动选择。

预设弹窗内的 **管理动作库**可修改名称和描述、设置单次／循环，以及导入 `.funscript`、截取时间范围、查看循环候选；导入细节在选好文件后出现。高速偏好收在高速预设中，恢复旧版标题在上、曲线在下的大行程高速／小行程高频卡片，宽度与下方动作卡片一致，窄屏自然换行，选择高频率后在该卡片底部显示行程缩短。动作池和动作库分别一次保存即生效，取消保留各自已保存的值；无需再保存外层设置。重命名同步更新三档动作池，删除同时从动作池和情景引用中移除；某档只剩这一个动作时须先在动作池里加入其他动作。联动数据域的 `motion-scripts/` 保存轨迹，`motion-library.json` 只保存名称、描述、播放方式和三档动作池。改名不重写轨迹，保存前保留上一份 `.bak` 及其引用文件，清理全部数据会一起重置。文件格式与恢复流程见 [动作库存储](funscript-storage.md)。

`[qq]` 的 `motion` 统一写 `{range, tier, action}`：`action` 是该档动作池里的动作名称，或 `auto`。名称不在该档动作池里时，程序按 auto 从该档池里抽一个。模型从 runtime 的“可选动作”收到每个动作的名称和描述，不是三档都能用的在后面标“（仅 …）”；轨迹点、权重留在程序内。段落写 `seconds`（5–120）时这段按秒数停留，点名动作和 auto 都适用；单次播放的动作在这段时间内重复播放。写在 motion 里的 seconds 会挪到段落上，其余动作照常执行。轨迹按档位速度整体拉伸，压进所选范围，受限速、限程和升速上限约束。相同选择与未指定动作的后续气泡沿用进度；暂停后保留进度并重新限速进入；改行程速度设置时用同一次抽取按新限制重新起步。单次播放完毕停止（写了 seconds 的段落除外）。每段显示后在预定间隔内没等到下一段即停止，最后一段按自动停止设置计时；新消息打断剩余段落时，当前动作仍受这一倒计时约束。退出、断连、改动作库或关闭时停止。真实传输沿用唯一播放器、限速限程与停止流程，没有第二套设备连接。

角色卡的“偏好动作”从动作库名称里勾选；动作库里已没有的名称不写进规则。

**高潮／温存预设**与慢速／中速／高速预设并排（紫色圆点），和右栏“高潮设置”打开同一个面板，不直接铺开动作卡片。上半部分是高潮：持续秒数、速度（中速／高速／自己填 unit/s，默认高速）、“选择高潮动作”和高潮提示词；下半部分是温存：高潮结束后进入温存或停止，选温存时再显示持续秒数、“选择温存动作”和温存提示词。选项即时保存，数字有效后失焦／回车保存。“选择…动作”打开轨迹卡片面板（选择、放大轨迹、出现频率、管理动作库），动作选择独立保存，取消丢弃。高潮动作池独立于三档动作池，未单独保存时沿用所选速度对应档的池；选中速或高速时按该档上限运行，该档不可用则往低档找；自己填的速度直接作为刺激速度，本场快调手动调过速度时以快调为准；都受总行程、速度上限、暂停与时长限制。温存动作池未单独保存时沿用最低可用速度档的池，按慢档、靠龟头的浅行程播放。管理动作库时，重命名和删除同步更新高潮／温存引用，各自至少保留一个动作。

QQ 回复中的表情按所在气泡显示，逐段显示结束后也不会移到整条回复开头；不同气泡可以重复使用同一表情。

## 使用

- 点击左侧 **新QQ会话**，直接打开 QQ Bot 对话；也可以点击 DSH 原生 **新会话**，在预设选择里选 **QQ Bot**。
- 新 QQ 对话首次进入时默认收起左侧栏；通过左上角原有按钮展开后保持，切回同一对话不重复收起。
- 插件不会把 `qqbot` 设为默认预设。如果你自己在 DSH 设置里把默认改成了 QQ Bot，关闭插件前请改回：设置 → Agent 预设 → 标准模式。否则关闭插件后新建会话会报 `Unknown agent preset`。
- 插件关闭期间，QQ Bot 的旧会话无法打开；重新启用后可以恢复。

### 角色

首次使用且没有角色库、预设和会话资料时，自动加入“大肥鱼”及其头像，并作为新 QQ 会话的默认角色；默认通用提示词使用项目方提供的《通用破限与规范》，放在“提示词”一栏，中间和结尾为空。内容均可在编辑器中修改。已有资料不覆盖，空角色库或已删除角色也不会补回；插件仍不会改变 DSH 的默认 Agent 预设。

平时在角色菜单 → **管理角色…**，或设置 → **QQ Bot**，进入独立编辑器的角色页新建和修改角色，只填名称和设定，名称不能和别的角色重复。角色库为空时右侧留白，点击“新建角色”才打开表单；头像与名称并排，保存角色后点击头像即可上传或更换。

头像右侧可设为或取消新 QQ 会话的默认角色。角色设定在主页面显示四行预览，点击打开与 QQ Bot 设置同尺寸的编辑框；保存直接持久化角色及当前表单改动，无需再次保存外层。取消或关闭编辑框只丢弃本次正文编辑，保留打开前的角色表单草稿。

QQ Bot 设置的“数据”页提供两种清理：

- **清理缓存**：释放本插件已生成的语音、提示词查看副本、角色显示与设备提示缓存，保留角色、设置和设备授权；之后需要时重新生成语音。
- **清理全部数据**：确认后删除本插件的角色、通用提示词、记忆、头像与背景、语音连接及凭据、接话和联动设置，并恢复首次使用的内置角色与预设。自动接话关闭，设备授权撤回，需重新手动配置。DSH 原生聊天记录保留。

清理结果会同步到其他已连接页面，离线页面重新连接后同步。旧页面的未保存草稿不能覆盖清理后的资料。正在进行的 QQ Bot 回复需先停止，已有设置保存完成后才能清理全部数据。宿主、其他插件的数据与共享浏览器缓存保持原样；“清理缓存”不会清除模型服务商的提示词前缀缓存。

角色卡存在 `~/.dsh/qqbot/roles/`（设了 `DSH_HOME` 时在 `$DSH_HOME/qqbot/roles/`）。编辑器新建的角色是一个目录 `r-<8 位十六进制>/ROLE.md`，frontmatter 里的 `id` 是插件内部用的键（会话绑定、头像、预设选择都按它记），不用管，也不要改。也可以自己写文件，`id` 可以不写，不写时用目录名或文件名：

```md
---
name: 爱丽丝
---

角色设定、性格、说话方式、示例对话……
```

选角色不用打命令：

- 新会话页：agent 模式选了 **QQ Bot** 以后，这一行右边出现角色菜单。选好再发第一条消息，这个会话从第一轮起就用这个角色，不再取新会话默认角色。也可以选"不用角色"。
- 会话开始后：点击输入栏左侧的角色名称打开角色菜单，当前角色打勾。对话空闲时可以切换或选择“不用角色”，下一轮生效，之前的消息和头像保留；生成中或有消息排队时暂时禁用。
- 菜单底部的"管理角色…"打开角色编辑器。

上述入口只在 QQ Bot 会话里出现。也可以用 `/role` 命令（只在 QQ Bot 会话里有）：

| 命令 | 作用 |
| --- | --- |
| `/role` | 当前角色、通用提示词、新会话默认角色和角色列表 |
| `/role <角色名称>` | 对话空闲时切换角色，下一轮生效 |
| `/role none` | 对话空闲时选择不用角色，下一轮生效 |
| `/role default <角色名称>` / `/role default none` | 设置或取消新 QQ 会话的默认角色，已有会话不变 |

改了角色卡文件后，打开一次角色菜单或执行一次 `/role` 就会重新读取。没在新会话页选过角色的会话，角色在第一条消息时按新会话默认角色定下来，记在 `qqbot/sessions.json`，重启后保留。

### 语音语气（0.36.0）

语音分段支持可选的 tone 语气说明。Fish S2 使用语气标签，drama-3 支持自由描述；OpenAI 兼容服务打开“支持语气说明”后，通过 instructions 发送给兼容网关。GPT-SoVITS 不发送语气。语气随请求传递并参与缓存区分，具体听感取决于服务和音色；本版只做模拟请求验证，未做真实试听。

### 聊天辅助

打开 QQ Bot 设置 → **聊天辅助**，设置作用于当前打开的 QQ Bot 对话。输入栏不再单独显示接话按钮，也不提供固定快捷短语。

- **自动接话**默认关闭。角色回复及分段显示完成后，输入框无草稿和附件、会话空闲时开始等待；默认 120 秒后让角色自然继续说一小段，每次重新生成，默认连续最多 6 次。等待时间与连续上限可调整。关闭设置窗口后继续计时；隐藏或离开页面、切换对话、出错或达到上限后关闭，返回不会自动恢复。
- **自动接话提示词**默认折叠，可编辑、保存和恢复内置默认；按对话保存在 `qqbot/auto-reply-prompts.json`。下一次自动接话使用已保存的文本，作为提醒追加到聊天末尾，不改变角色系统提示词前缀。
- **快捷回复选项**默认开启，可独立关闭并按对话保存。模型在正常回复中一起起草三条用户视角的下一句。“点击后”可选“直接发送”或“仅填入回复栏”，默认直接发送。点击方式按对话记住，保留已保存的选择；输入框已有草稿或附件时不覆盖。自动接话不会替用户选择任何候选。
- **回复建议提示词**可编辑、保存和恢复内置默认，按对话保存在 `qqbot/quick-replies.json`；关闭建议后保留自定义文本，再开启继续使用。保存失败保留草稿。修改当前开启会话的建议提示词会改变 EXT（500）段及之后的前缀缓存；内置默认原文不变。

### 设备联动（0.2.0 起内置）

只安装 `dsh-qqbot` 即包含设备联动。QQ Bot 设置新增“联动”页，顶部“启用设备联动”默认开启（已有明确关闭选择保留）；开关自动保存。开启功能不等于首次授权、连接设备或接入对话，后三项仍由用户手动操作。已有独立插件的设置、浏览器服务地址继续使用；没有设置时保持未授权。

- 联动页管理授权、行程速度、动作细调、紧急停止快捷键、补充互动规则和气泡标注；运动参数自动保存，补充互动规则独立保存。“AI主动性”旁点“设置”会说明各角色分别设置，并可前往角色页，自动展开“联动设备”分组。自主性与偏好动作仍在各角色里设置。
- 连接方式与服务地址（IP:端口）放在右侧“设备联动”的“连接设置”中，按浏览器即时保存；连接成功后自动折叠，点击可展开查看，连接期间锁定编辑，断开后自动展开。支持 Buttplug 和蓝牙；蓝牙需要 HTTPS 和支持 Web Bluetooth 的浏览器。
- QQ Bot 会话输入栏底部的“设备联动”和右栏“开始”页中浏览器下方的同名卡片，都打开宿主原生右侧联动标签页。提供连接／断开、接入／退出对话、暂停／继续、当前动作及保护停止倒计时。桌面可收起、调整宽度；窄屏沿用宿主全屏面板。输入栏保留暂停／继续按钮。右栏“设置”打开 QQ Bot 联动设置页；首次授权也在设置里完成。收起右栏不停止或恢复设备。
- 右栏只显示所属会话的动作，切到其他会话不显示前一会话动作；接入新会话仍先停止旧会话。倒计时读取现有看门狗，暂停时冻结，不因显示而延长运行。
- 右栏顶部是状态卡（状态、连接、设备、当前动作、阶段、剩余时间、位置条），“联动设置”打开设置的联动设备页。接入后可用：
  - **本场调整**：双端行程滑条直接选择实际起止坐标（0–100），速度滑条设置目标速度（unit/s）。手动调整的项本场生效，未调的项跟随 AI，复原后全部交回 AI；退出联动或换会话清空。仍受总限程限速、起步和升速约束；不保存长期设置，不修改提示词。
  - **手动定位**：滑条 0–100 映射到总设置行程，慢速移到位后停住；拖动打断当前 AI 动作，AI 的下一段照常接管。暂停会结束手动定位，保持 30 秒后自动停止。
  - **高潮**：按下后设备立即从高潮动作池随机选预设，按设定速度刺激 5–120 秒（默认 20 秒、高速），同时向 AI 发一条“高潮”提示词，告诉它刺激秒数，让它用角色口吻只写高潮过程，段数随秒数增加（约每 3 秒一段）；转入温存时再发一条“温存”提示词，单独写事后温存（约每 4 秒一段）。两条提示词可在高潮／温存预设面板里改写和恢复默认，{秒数}、{段数} 发送时填入。发送失败不影响设备。期间 AI 回复照常出字，但其中的动作不执行。刺激中可“取消高潮”、温存中可“结束温存”（停在原位，不退出联动，并撤回还没处理的提示词）。刺激结束后默认进入温存（从温存预设随机选动作，慢档、靠龟头的浅行程，默认 60 秒），可在设置里改为停止。暂停按钮和快捷键随时可停。
- 总开关关闭时，本页立即停止、断开、退出对话，释放暂停的文字时钟，撤掉右侧联动标签、底部与开始页入口、输入栏暂停按钮与动作标注，并撤销设备提示词和角色页的联动能力。设置和授权资料保留，再开启不会自动连接或接入。
- 其他已打开页面通过 owner 接口的长轮询同步；快速关闭再开启、宿主重启也使旧控制状态失效。同步中断时停止并断开；同步恢复不自动连接。浏览器或网络挂起时仍受原有程序超时限制。
- 暂停按钮、限速限程、首次慢速进入及末段 30 秒停止保持原机制；不增加聊天停止词检测。暂停快捷键默认不设，推荐 Ctrl+M。
- **安全词降速**：联动设备设置中可选开启，默认关闭。预填“慢一点、太快了、轻一点、受不了了”，可添加或删除。发出的消息包含任一词句时，程序直接降一档速度，保持当前行程和动作，等 AI 新回复接管；急停仍用暂停快捷键或按钮。
- 当前支持 Buttplug（Intiface / ServeUCentral），以及 ServeU／VorzePiston V0 蓝牙直连（安卓 Chrome／iOS Bluetooth Browser＋HTTPS，待实体设备验收）。

**从两包升级：**先备份 profile 配置、锁文件和两个已安装插件，再在 DSH 插件管理里停用或移除独立的 `dsh-toy-buttplug`，保留数据，然后安装合并版。安装后逐文件核对，按宿主提示手动重启。检测到旧独立插件仍启用时，内置联动不登记、不连接，并在联动页说明；插件不会擅自修改旧包或其他插件配置。仅关闭内置开关不会关闭旧独立插件。

**数据与接口：**角色等资料仍在 `<DSH_HOME>/qqbot/`；设备设置仍在 `<DSH_HOME>/toy-buttplug/settings.json`，新增可选 `enabled` 字段，旧设置未写时视为开启。浏览器仍使用 `dsh-toy-buttplug:connection` 保存服务地址。内置接口改为 `/api/qqbot/toy/state`，防止和旧包路由碰撞；属于内部接口，不读入更早的 `dsh-serveu` 旧数据。

**前缀缓存：**合并不改提示词文字、顺序及上下文布局。仅功能关闭时，已接入会话的设备段落从 order 500 移除，runtime 的 device 行撤销；再次开启不会自动恢复接入。角色、语音、记忆和中文压缩模板保持原行为。

### 分段回复

QQ Bot 会话里，模型用一个 `[qq]` 块把回复分成几段，界面依次显示。“界面 → 段落间隔”统一管理普通聊天和设备运动时的间隔。普通聊天可选短／中／长（上限约 2.8／4／5.6 秒，默认中），每段出现前按下一段字数模拟打字（一点思考停顿加每字耗时，随机 ±25%，最少 0.3 秒），期间显示“对方输入中…”；生成慢于打字时下一段一到就出现。设备运动时可自填 1–120 的整数秒，默认 5 秒；写了新动作的段落停满所设秒数，动作没变的接续段只停到读完（至少 2 秒、不超过所设秒数）。右侧联动栏的“段落间隔”共用同一份持久设置，两处同步，退出联动或重开仍保留；已有自定义秒数保留。段落间隔不改变设备运动速度。“联动设备 → 回复结束后”默认等待 30 秒后停止，可自行调整等待时间或切换处理方式。格式见 `src/vendor/dialogue-timing/protocol.js` 的 `SEGMENT_PROMPT`。

- 只有本页打开后生成的回复才逐段出现；历史消息直接全部显示。系统设置了"减少动态效果"时也直接全部显示。
- 生成过程中第一段一写完就出现，之后每段按间隔出现；到点了下一段还没生成出来，就等它生成出来再显示。切到别的会话时计时照常走。
- 逐段显示途中你发了新消息，没出现的段落就不再出现。这只记在页面内存里，刷新后完整显示。
- 中途停止生成时，已经写完的段落照常显示。
- `[qq]` 块格式不对时显示"分段回复格式无效，请让 AI 重试"。段落里多写的字段直接忽略，不算格式不对。JSON 本身坏了（常见于正文里没转义的引号或换行）时尽量抽出文字显示，丢掉所有动作，设备插件会停下；悬停可以看到"格式有误"。
- QQbot 显示时按实际换行和 `[表情: 描述]` 标记拆气泡，去掉气泡首尾空白，不生成空气泡；普通空格和标点保留。没有 `[qq]` 块的普通回复也适用。代码块和行内代码保留原格式。同一协议段拆出的气泡一起出现，沿用该段的动作和计时，调试标注放在该段最后一个气泡后。
- 表情描述不参与语音合成；纯表情不生成语音条。图文分开后，正文按原有语音显示偏好呈现。
- 标准会话不处理 `[qq]` 块。

### 表情

装了 [dsh-meme](https://github.com/yyh-001/dsh-meme) 时，QQ Bot 会话的系统提示词里有一段表情规则：用 `send_meme` 找图、一次最多一张，以及当前角色的表情频率。dsh-meme 自己的"斗图规则"不进 QQ Bot 会话，发送方式（Web 标记、纯文字模式等）仍按 dsh-meme 的设置和工具说明。没装或关掉 dsh-meme 时这段不出现。

角色页以角色设定为主，表情包、音色、联动玩具各有带分割线的折叠区，默认收起，标题只显示分组名称。窄屏时角色列表横向排列，给表单留出完整宽度。

角色和通用提示词使用独立保存操作；保存失败保留草稿，离开前可选择继续编辑或放弃。头像单独保存。

“界面”保留六张色板／背景卡，修改自动保存，示例聊天同步显示色板、背景、头像与气泡尾巴；手机可展开预览。“语音”中的已配置服务可展开管理，音色的“用于角色”入口需要先选择目标角色，再确认替换并保存；关闭语音只保留总开关，并停止、取消当前试听。

### 手机连接（本地局域网）

电脑端打开 **QQ Bot 设置 → 手机**，开启“启动连接”，将“手机网址”和“访问码”复制到同一局域网的手机浏览器中登录。默认关闭；电脑和 DSH 需保持运行。端口或网络需要调整时，先关闭连接，在“连接设置”中选择并保存；有多个网络时按名称选择当前 Wi-Fi／有线网络。

手机复用这台 DSH 的会话、QQ Bot 角色、设置、语音及图片接口，仍使用原生会话和工具权限。登录有效期为 12 小时；手机输入栏的“退出”、电脑关闭连接或插件停用都会撤销对应连接。访问码保存在 `<DSH_HOME>/qqbot/phone/settings.json`，不读取旧皮肤插件资料；“清理全部数据”会关闭入口并重新生成访问码。

仅手机入口的 QQ 会话应用窄屏侧栏覆盖层和可视高度适配；标准会话沿用宿主布局。连接管理与访问码只在电脑显示。首次连接如果被系统防火墙拦截，需要在本机允许该局域网连接；插件不修改防火墙规则。同一局域网可继续使用 HTTP 入口；安卓蓝牙使用下方「Tailscale HTTPS 与手机蓝牙」入口。设备直接连接访问页面的手机，不经过电脑代转发。

表情区可选优先图库、偏好标签、频率和补充提示词；图库及真实标签从 dsh-meme 的只读接口获取，只在展开时读取。不选图库时列出全部标签；换图库不自动删除已选标签。这里只做优先使用，没有合适候选时可以使用其他已启用图库，不改变 dsh-meme 的全局设置或图库开关。图库仍须在 dsh-meme 中启用。

编辑器在表情插件启用时显示表情区，停用时保留已有偏好，再启用后恢复。读取失败时保留已有选择，可重试或清空后保存；“清空表情偏好”只修改草稿，取消或放弃不会写入。联动区只在内置联动开启且无旧包冲突时出现。以下字段也可写在角色卡 frontmatter 里：

```md
memeFrequency: low   # low 低 / medium 适中 / high 高 / off 不主动发；不写时为适中
memePacks: [{"id":"pack-id","name":"图库名称"}]  # 由编辑器选取，界面不显示内部 id
memeTags: ["happy", "meow"]
memePrompt: "优先可爱的表情。\n没有合适的不用勉强发。"  # JSON 字符串，支持换行，最多 4000 字符
proactivity: follow  # 设备联动自主性：follow 低 / situational 中 / high 高；不写时为低
proactivityTexts: {"follow":"这个角色的低自主性说明。\n可换行。"}  # 单行 JSON，每档最多 2000 字符
motionActions: "steady, slide"   # 偏好动作，逗号分隔：steady accelerate decelerate intermittent fast_out slow_out slide
motionRanges: "full, upper"      # 偏好范围，逗号分隔：full lower_half upper_half lower middle upper
```

两组偏好都未勾选时，设置页显示“无勾选＝动作和范围无特殊偏好，按用户要求、剧情和人设选择。”；勾选任意一项后隐藏，全部取消后重新显示。这句只在设置界面显示。

`proactivity`、`proactivityTexts`、`motionActions`、`motionRanges` 交给内置设备模块，不改运动限制。角色页的“联动”里可设置“自主性”“偏好动作”“偏好范围”。自主性下拉菜单显示三档完整含义，窄屏自动换行；“自主性提示词”在角色表单内折叠展开，默认编辑当前档位，也可切换其他档位；每档独立保存、取消或恢复默认，不提交角色名称、正文和其他档位草稿。自主性档位与说明只在角色卡设置，设备插件直接使用该档位，没有会话临时档；未设置时为低自主性。未改的档位使用内置联动模块提供的默认说明，原来保存在联动设置中的自定义说明继续作为默认。空白说明只保留程序添加的档位标题。默认说明仅在展开时读取，读取失败可重试，不影响已有角色草稿。改当前角色当前档的提示词从设备槽位 order 500 起影响前缀缓存，单纯移动编辑入口无影响。

表情偏好只进入 qqbot 会话的 `qqbot:format-meme`（有 `send_meme` 时）；切换、清空角色后不沿用旧偏好。普通聊天期间提示词稳定；修改偏好从该段（order 410）开始改变前缀，之前的破限、角色正文和分段规则不变。dsh-meme 的目录接口受它自身的本机/LAN 访问设置约束，拒绝访问时此处会提示读取失败，不自动更改其访问设置。

### 长对话压缩

QQ Bot 会话用 DSH 原生的 compaction-basic 压缩：阈值、保留最近多少原文、自动压缩和 `/compact` 都和标准会话一样。只有摘要模板不同，改成中文聊天存档，栏目是人物与称呼、关系进展、经过、当前场景、约定与待办、用户偏好，没有内容的栏目整栏省略。标准会话仍用 DSH 的英文编程模板。

实现在 `src/compaction.ts`：继承 `BasicCompactionEngine`，只覆盖它注明的唯一子类钩子 `summarize()`，挂在 qqbot 预设自己的隔离组里。摘要前后的框定语（"This is an automatically generated checkpoint…"）由 compaction-basic 写入，没有换。

### 跨会话的角色记忆

每个角色有一份记忆，记的是和用户之间下次见面还用得上的事，栏目固定：称呼与身份、关系、偏好与禁忌、约定与待办、重要经历，总共不超过 1500 字。角色编辑器的“记忆”里可以查看、修改，或点“整理记忆”用最近一次和它的聊天整理一次。

- **什么时候进提示词：**角色在会话里第一次出场时取一份快照（`qqbot:role-memory`，order 800），整个会话都用它，重新打开旧会话也不变。会话中途整理出的新内容，从下一个新会话起生效。
- **什么时候自动整理：**距上次整理至少新增 10 轮，且满足其一：AI 回复后 20 分钟没有新消息；会话要压缩时；用这个角色开了新会话。手动整理不受轮数限制。只整理还开着的会话，DSH 关掉前没整理的内容不再补。
- **整理请求：**回放本会话的系统提示词和历史，整理指令和旧记忆作为最后一条 user 消息，输入基本能命中前缀缓存。结果超长时让模型重写一次，还超长就保留旧版。整理期间手动改过记忆，这次结果丢弃。会话里换过角色时，只整理当前角色。
- **存储：**`<DSH_HOME>/qqbot/memories/<角色 id>.json`，不写进角色卡。删角色时一起移进回收站。

**缓存影响：**记忆在压缩之间不变，平时每轮仍命中缓存，用同一版记忆的会话共用前缀。记忆更新后，新会话从 order 800 开始和旧会话不同。旧会话第一次在新版本里组装时会取一次快照，从 order 800 起失效一次。

**已开始的对话：**手动修改或点“总结记忆”后，这个角色已开始的对话从下一条回复起使用新版；代价是多一份完整系统提示词，或从开头重算历史，取决于模型路由。自动整理（空闲、开新会话）出的新版等该对话下次压缩时换上，压缩本来就要重算历史，只多让系统提示词从 order 800 起失效一次。

### QQ 界面

只在 QQ Bot 会话的聊天区生效，标准会话、侧边栏和弹窗保持 DSH 原样。在编辑器的"界面"页设置，保存后立即生效：

- 色板：经典蓝、炫彩紫、简洁白、经典绿气泡、深空黑，以颜色卡片选择，跟随 DSH 的主题。自定义背景是第六张卡片：选图并裁剪后启用，可更换、移除和调整显示方式；切回普通色板会保留图片，再点自定义即可恢复。
- 气泡尾巴、助手头像、聊天区最大宽度、沉浸模式（隐藏思考和工具过程）；“隐藏思考过程”默认开启，保留用户手动选择。
- 气泡标注：“隐藏动作信息”和“隐藏段落倒计时”默认开启，可独立调整并自动保存，设备联动开关始终保留这两个显示偏好。选择保存在联动插件中，不影响设备动作或提示词；停用联动插件后这一栏消失。
- 聊天背景：一张图片，可选铺满、完整显示或拉伸。选图后在裁剪弹窗里取景，比例可选当前对话比例、16:9、4:3、9:16 或原图比例，保存时缩到最长边 1920 像素。
- 角色头像：在角色页上传，选图后在裁剪弹窗里拖动取景、缩放，裁成正方形、缩到 256 像素。没有头像时显示角色名首字。

设置存在 `qqbot/ui.json`，图片存在 `qqbot/images/`（头像在 `avatars/<角色内部 id>.<扩展名>`）。删除角色时头像一起移到 `roles-trash/`。这些设置不进提示词，不影响前缀缓存。

每条回复显示当时那个角色的头像：换人后，之前的消息不变。每轮用的角色记在 `qqbot/sessions.json` 的 `turns` 里，只在换人时追加一条，不进提示词。角色改名后旧消息跟着显示新名字；删掉的角色在旧消息上不显示头像。没有选角色的会话（没选过角色，也没设新会话默认角色）不显示头像。

### 语音

点击“查看教程”直接新建标准对话。DSH 先确认是否已有本地部署的 AI 语音服务，有则协助接入，没有则按 Fish Audio 的 `s2.1-pro-free` 免费路线完成配置。教程不携带已有配置或密钥，不影响 QQ 聊天前缀缓存。

开启语音、给当前角色选好音色后，可在“朗读偏好 → 发送方式”选择：

- **由 AI 决定（默认）**：大部分消息用文字，只在用户要求语音或语境合适时偶尔发语音。AI 在对应 `[qq]` 段落加 `"voice":true`，`text` 仍是要说的话；未标记的段落和普通回复保持文字，同一条回复可以混合两种气泡。只有一句语音也使用 `[qq]` 块。
- **全部转语音**：沿用所有可朗读回复转成语音条的行为，不需要 AI 标记。

```text
[qq]{"version":1,"stages":[{"text":"我在呢。"},{"text":"晚安，做个好梦。","voice":true}]}[/qq]
```

点一条语音，从它开始依次播放本条回复中其余的语音段落。新设置和旧配置中未保存过发送方式的情况均默认“由 AI 决定”；已有服务、音色、总开关及朗读偏好保留。

`qqbot:format-voice` 提供固定用法说明（order 420），`qqbot:runtime` 的 `voice` 行按当前会话报告发送方式、总开关关闭、未选音色或配置失效；不发送密钥、地址或内部键，也不探测上游连通性。首次加入说明时从 order 420 开始改变前缀；之后开关语音、切换发送方式或换音色只更新 runtime，不改这段固定说明。

在编辑器的"语音"页设置：

1. 在“语音服务”里添加服务，支持三种：
   - **Fish Audio**（仅作使用推荐，非商业推广）：填 API key，模型默认 `s2.1-pro-free`，建议先免费试用；满意后可充值 API 余额并手动改为 `drama-3`，支付宝以结账页提供为准。价格按 UTF-8 字节计算，见 [官方价格页](https://docs.fish.audio/developer-guide/models-pricing/pricing-and-rate-limits)。直连不稳时打开"使用代理"，填代理软件的 HTTP 或混合端口（默认 `127.0.0.1:7897`）。只支持 HTTP 代理，不支持 SOCKS。不勾选时按 DSH 自己的网络设置（`$DSH_HOME/.env` 里的 `HTTPS_PROXY` 等）。
   - **OpenAI 兼容接口**：OpenAI 的 `/audio/speech` 格式，SiliconFlow、Kokoro-FastAPI 等云端或本地服务。地址填到 `/v1`，本地服务一般不用 key。
   - **GPT-SoVITS**：自带的 `api_v2.py`，地址默认 `http://127.0.0.1:9880`。
2. 保存服务后点“添加音色”：Fish 填音色 ID（可以直接粘贴音色页地址）；OpenAI 兼容接口填 voice 名称；GPT-SoVITS 填参考音频在那台电脑上的路径、参考音频的文字和语言。只有一个服务时自动选中，可以先试听再保存。
3. 保存音色后点“去角色页使用”，给角色选音色。音色列表显示哪些角色正在使用，并提供试听、编辑和更多操作。

页面顶部是语音总开关，下方依次为“语音服务”“音色”“朗读偏好”。服务卡片显示密钥和 Fish 代理状态，点“设置”修改；Fish 代理直接可见，名称和模型直接显示在表单中；模型仍可手填。服务和音色使用独立编辑表单，点保存后返回概览，离开未保存表单会提醒。

“朗读偏好”包含显示方式（语音条点开显示文字 / 只有语音条 / 语音条和文字）、生成时机（点击时生成 / 新回复提前生成）和音量，修改后自动保存。删除入口在各卡片的更多菜单里，确认时显示受影响的音色或角色；仍有音色使用的服务不能删除。

朗读时去掉括号和星号里的动作描写、链接和代码；只有动作描写的气泡照常显示文字。合成过的句子在 DSH 进程和页面里各留一份，重复播放、刷新页面不会再请求。历史回复不提前生成，点了才生成。

连接、音色和设置存在 `qqbot/voice.json`。API key 不在这个文件里，存在 DSH 的凭据库（`$DSH_HOME/.credentials.yaml`，记录名 `dsh-qqbot/tts-<连接内部 id>`），界面上只显示有没有存。删除连接时一起删掉它的 key；卸载插件不会自动清掉凭据库里的记录。合成请求由 DSH 进程发出，key 和本地服务的地址都不经过浏览器。

装了 dsh-fish-tts 并打开它的"自动朗读"时，QQ Bot 会话的回复会被读两遍，在 QQ Bot 会话里用时把它的自动朗读关掉。

### 角色与提示词模板编辑器

普通偏好自动保存：开关和选择立即提交，数字在失焦或回车且有效后提交，滑条在松手或完成键盘调整后提交。保存失败保留输入并提供重试。角色、通用提示词、语音服务、音色、动作库、动作池和自定义提示词采用明确的保存操作，成功后即可重开查看。表情补充提示词、自主性各档说明与跨会话记忆分别保存，不提交其他角色草稿；已有角色保存后也保留这些编辑区尚未保存的文字。新角色首次保存需要先创建角色资料。头像裁剪另行一次保存。

自动接话、快捷回复选项、表情补充提示词、自主性提示词和补充互动规则共用折叠文本编辑区：保存、取消、有内置文本时恢复默认；表情补充提示词提供清空。恢复默认或清空后立即保存，失败在原编辑区显示并保留草稿。跨会话记忆沿用记忆分区，提供独立保存、取消与总结记忆。动作描述只统一输入框样式，继续随动作名称一起保存。角色设定与通用提示词编辑器保持原样，内置提示词内容及组装顺序不变。

左下角"更多" → 设置，点击侧栏的 **QQ Bot** 即关闭 DSH 设置窗口并打开独立编辑器；也可以从新会话或对话输入栏的角色菜单选择"管理角色…"进入。角色页直接管理角色，不再有角色／通用提示词二级标签。角色里的“提示词”折叠栏通过下拉框选择模板，旁边的“管理模板”按钮打开同 QQ Bot 设置尺寸的独立弹窗并定位当前模板，保留原角色草稿；新建、复制和删除都在管理窗口内操作。提示词查看器的编辑入口直接打开模板弹窗并定位对应模板；角色库为空时也可管理模板。

- 角色：新建、修改名称/简介/设定/表情频率/联动主动性上限/偏好动作和范围/音色、删除、设为新会话默认。提示词模板按名称选择，绑定随角色保存；新模板在弹窗保存后自动选给当前角色，返回继续编辑。模板独立保存，不会提交或丢弃角色的其他草稿。旧角色未单独选择时先显示当前生效的预设，保存后固定为这份；之后改默认预设不会改掉已保存的选择。角色文件里手写的其他字段原样保留。删除的角色移到 `qqbot/roles-trash/`，放回 `roles/` 就恢复。
- 提示词模板：左侧模板列表，右侧编辑正文，显示使用它的角色数量。默认只显示一段“提示词”，放在系统提示词最前；“高级”默认折叠，展开后可选填“中间”和“结尾”，分别放在角色设定之后、系统提示词最后。折叠不影响已有内容生效和保存。可以新建、复制、修改、删除（至少留一份）、设为默认。没有单独选择的角色和无角色会话用默认预设。关闭弹窗放弃该模板未保存的修改，保留外层角色草稿。
- 保存后下一条消息起生效。改动会让用到它的会话下一轮的前缀缓存从改动处开始失效，平时不要频繁改。
- 角色和通用提示词都只按名称显示，名称不能重复。内部 id 自动生成，界面上看不到，改名不影响已有会话、头像和预设选择。

通用提示词存在 `qqbot/presets.json`；没有这个文件时用内置《通用破限与规范》。首次初始化会保存默认角色与预设的关联；已有资料继续保留其保存的预设。编辑接口走 DSH 自己的认证，只有 owner 能读写。

### 导入配置

QQ Bot 设置底部点 **导入配置**，选择 JSON 配置包或 ZIP，查看预览后点“确认导入”。ZIP 内只放一份 JSON 配置，可放在文件夹中；普通加密 ZIP 会弹窗要求密码，输错可重试，取消不导入。密码只用于浏览器内本次解密，不上传或保存。可以单独选择角色或通用提示词；重名默认跳过，也可以选择“另存一份”，由程序生成唯一名称并保留角色与预设的关联。已有角色、预设、默认选择和会话绑定不变。导入时有未保存的编辑会先提醒处理。

配置包示例见 [`examples/config.json`](../examples/config.json)，替换里面的名称和提示词即可分享。只发预设时可省略 `roles`，只发角色时可省略 `presets`；每类最多 100 项，文件不超过 10 MB，ZIP 解压后的 JSON 也不超过 10 MB。配置包格式：

```json
{
  "format": "dsh-qqbot-config",
  "version": 1,
  "presets": [{ "name": "分享预设", "head": "自己的提示词", "mid": "", "tail": "" }],
  "roles": [{ "name": "分享角色", "persona": "角色设定", "preset": "分享预设" }]
}
```

- `presets` 每项填写名称和 `head`（主提示词），`mid`、`tail` 可省略，省略时为空。
- `roles` 每项填写名称和 `persona`（设定），`description` 可省略；`preset` 按名称关联本包或本机已有的预设。没有填写时，导入后固定选择当前 QQ 默认预设。如果预设只在包里，导入角色时须同时勾选预设。
- 角色还可带 `memeFrequency`、`memeTags`、`memePrompt`、`proactivity`、`proactivityTexts`、`motionActions`、`motionRanges`，格式与角色卡一致。内部 id 由程序生成，不在配置包里填写。
- 当前配置包只接受上述角色和预设字段；不接受旧插件文件、本机存储文件、界面设置、语音服务／音色、密钥、头像、图库绑定、设备参数或授权。遇到未知字段会明确报错，避免只导入了一部分而不知情。
- 预览和取消不写配置；确认时先备份原 `presets.json`（如存在）及新增条目清单到 `<DSH_HOME>/qqbot/import-backups/<时间-随机编号>/`。导入写盘失败会撤销本次新建的角色文件；原有资料不被覆盖。其他窗口改过资料库时，需重新预览再导入。
- 在已加载此版本的 DSH 中导入后立即可选，不需要重启。导入本身不改变现有会话的提示词；之后选择新角色或预设时，按原有规则从相应段落开始影响前缀缓存。

### 提示词查看器

QQ Bot 会话顶部，与“对话”“轨迹”并列的 **提示词** 标签。窗口较窄或手动收起时，在这一排的“…”菜单里打开。查看器在内容区只读显示这个会话发给模型的内容：

- 系统提示词的每一段：名称、order、来源插件、字数、在前缀里的位置。可以按段落或按来源分组。
- 和上一轮实际发出的系统提示词对比。有变化时标出从哪个字符开始不同，也就是下一轮前缀缓存从哪里失效。DSH 重启后要先发一条消息才有对比。
- runtime context（工作目录、各插件登记的运行时状态）和上一次请求带的工具。

查看器只读；角色和通用提示词的段落旁有"编辑"，跳到编辑器。外部插件的内容到插件设置里改。接口走 DSH 自己的认证，局域网或远程访问的非 owner 读不到。会话要先打开或发过消息（agent 已加载）才能查看。

## 给其他插件：登记接口

host 层服务 `ctx.qqbot` 只做登记，内容只出现在 qqbot 会话里。用可选依赖接入，没装 dsh-qqbot 时什么也不注册：

```js
ctx.inject(['qqbot'], (child) => {
  // 规则：在提示词里的段名为 qqbot:ext:toy。文本应尽量稳定，每次变化都会让后面的前缀缓存失效。
  child.effect(() => child.qqbot.extension({ name: 'toy', text: session => '...' }))
  // 运行时状态：进入 qqbot:runtime context，不影响系统提示词前缀。
  child.effect(() => child.qqbot.runtime('toy', session => 'device=disconnected'))
  // 会话当前角色：{ id, name, proactivity?, motionActions?, motionRanges? }，没有角色时为 undefined。每次现读。
  // 没选过角色的会话按新会话默认角色返回；判断是否 qqbot 会话用 ctx.agentPresets.presetForSession(agent.session) === 'qqbot'。
  // id 是角色内部键（0.23.0 起），改名不变，可作外部插件按角色存储的键，不要显示给用户。
  child.qqbot.role({ id: sessionId })
})
```

- `name` 只能用小写字母、数字和连字符。
- 登记时会自动记下你的插件包名，提示词查看器里显示为这段内容的来源。
- `text` 可以是字符串，也可以是 `(session) => string`。返回空串表示该会话里不出现这一段。
- 外部条目统一排在角色和格式规则之后、通用提示词结尾之前，同位置按名称排序。顺序表在 `src/order.ts`，外部插件不指定数字。
- qqbot 会话的系统提示词只由 dsh-qqbot 组装（一个 complete section）。直接调用 `ctx.systemPrompt.section` 注册的全局段落不会出现在 qqbot 会话里，DSH 自带段落也一样；工具不受影响。

### 浏览器端：分段显示时钟

浏览器端服务 `ctx.qqbotSegments` 让其他插件跟着 `[qq]` 分段的显示走，例如设备在每段出现时动作。只有 qqbot 会话里本页实时生成的回复会触发；历史消息和标准会话不触发。

```js
ctx.inject(['qqbotSegments'], (child) => {
  child.qqbotSegments.register({
    // 第 index 段显示后停多久（毫秒）；返回 undefined 时用 qqbot 自己的间隔。结果限制在 0–120000。
    durations: (session, reply, stages, index) => undefined,
    // 第 index 段刚显示。holdMs 是到下一段的预定间隔，回复已完整且这是最后一段时为 undefined。
    revealed: (session, reply, index, stage, holdMs) => {},
    // 这条回复不会再有新段落：complete / interrupted（用户发了新消息）/ failed / closed。
    ended: (session, reply, reason) => {},
  })
  const resume = child.qqbotSegments.pause(sessionId) // 文字停在当前段，resume() 后接着走剩余时间
})
```

- `reply` 是 `"<turn>:<step>"`，同一条回复在流式和完成后不变。`stage` 原样来自 `[qq]` 块，含 `motion`、`seconds` 等扩展字段。
- 每条实时回复：若干次 `revealed`，最后恰好一次 `ended`。流式时下一段可能晚于 `holdMs` 才出现；回复变完整时如果最后一段早已显示，会补一次 `holdMs` 为 `undefined` 的 `revealed`。
- 登记和暂停都随调用方插件停用自动撤销。回调抛出的错误只记日志，不影响文字显示。
- 类型见 `src/client/reply-clock.ts` 和 `src/client/segments-service.ts`；请按结构自己声明，不要运行时引用本插件的代码。

只读气泡旁显示可用 `child.qqbotSegments.annotate(Component)` 登记，返回撤销函数，并随调用方停用自动撤销。
组件收到 `{ session, reply, stages, index, playback }`（类型见 `src/client/segment-annotations.tsx`）。
`playback()` 返回当前段序号、状态（`history` / `running` / `paused` / 四种结束原因）和实际剩余毫秒数；读取不推进时钟、不通知设备。
时钟状态变化会重绘；倒计时刷新由组件按需订阅自己的界面定时器，并在暂停、结束、隐藏和卸载时清理。
挂点由 QQbot 定位在正文复制源之外，扩展不要再次包装渲染器、修改正文或触发动作；历史不应按当前设置推算旧时间。
关闭显示只撤销 `annotate`，不撤销 `register` 的运动回调或 `pause`。普通文本回复和标准会话不提供分段挂点。

### 手机远程蓝牙：Tailscale HTTPS（0.10.0）

1. 电脑和安卓手机安装 Tailscale，登录同一账号并连接；在 Tailscale 后台开启 MagicDNS 和 HTTPS。HTTPS 证书中的机器名会进入公开证书透明日志，手机同时使用其他 VPN 可能与 Tailscale 冲突。
2. 电脑 QQ Bot 设置 → 手机，选择「远程」，启动后复制自动生成的手机网址和访问码。
3. 安卓用 Chrome、iOS 用 Bluetooth Browser 打开该 HTTPS 网址，输入访问码。进入 QQ 会话右侧「设备联动」，先完成首次授权，再在连接设置选择「蓝牙」，点击「连接设备」并在系统选择器中选择设备，然后启用联动。
4. 首批沿用抚物 V0 协议，识别 ServeU、VorzePiston 广播名。连接先读取 D0 机内限制；尚无安卓实体设备验收，不保证其他型号或固件可用。

远程模式的手机网关只监听电脑 127.0.0.1，Tailscale Serve 负责 HTTPS，自动读取本机域名；不需要输入路径、域名或设备 id。已占用的 HTTPS 入口会显示冲突，不覆盖既有服务。同一目标的既有映射可复用；本次创建的映射在关闭入口或停用插件时核对后撤销，复用的映射保留。不使用公网 Funnel。已有局域网入口保持原样，但 HTTP 入口无法使用网页蓝牙。

电脑 DSH 保持运行且不能休眠。手机页面进入后台、锁屏、离线或联动状态同步失败时，程序停止继续发动作并断开；回到前台后手动重连。蓝牙协议已经发出的单包仍可能走完。iOS 使用 Bluetooth Browser（开发者 Angelo Cammalleri），网页蓝牙功能免费，有可选内购；[App Store](https://apps.apple.com/app/bluetooth-browser/id6455128847)。本插件的 iOS 真机链路待验收。

Tailscale 安装、登录与 HTTPS 初次开通由用户完成；程序只在用户启动远程入口时配置 Serve。说明参考：[Tailscale Serve](https://tailscale.com/docs/features/tailscale-serve)、[Chrome 网页蓝牙](https://developer.chrome.com/docs/capabilities/bluetooth)。


“手机”页提供两项：**局域网**（手机和电脑在同一个 Wi-Fi 下）、**远程**（不在同一个 Wi-Fi 下，例如手机使用流量）。同一 Wi-Fi 需要网页蓝牙时也可以用远程方式获取 HTTPS。

点击连接方式下方的 **“查看教程”**，会按当前选项新建标准对话并发送对应教程，让 DSH 逐步协助配置。远程教程覆盖 Tailscale 安装与登录、MagicDNS／HTTPS、手机网页和蓝牙；局域网教程覆盖同网 Wi-Fi 连接与排障。按钮在连接未启动时也可用；自动打开失败时提供可复制引导。教程不携带访问码或已有设置，不改变 QQ 聊天前缀缓存。

### 动作结束与待机缓动（0.12.0）

QQ Bot → 联动设备 → 回复结束后，可选延时停止、持续当前动作或转入待机。默认仍为30秒停止；延时时间可自设1–86400秒。待机从动作库选择预设，在“待机细调”中设置行程及速度（受总限制约束），末段超时后循环播放；新动作接管，暂停、退出、断开和错误仍通过原播放器停止。段间未等到下一段的保护停止、手动定位、高潮和温存的独立计时不变。“回复结束后”与高潮、温存选项合并在同一区块，不再显示分组标题；暂停、恢复快捷键常显，撤回授权放在联动页底部。


手机页直接显示当前连接方式的设置：局域网可选择使用网络，两种方式均可调整访问码和端口。配置后点击“启动连接”；“停止连接”后仍可编辑设置。
