# 本地设备连接器 0.1.1

服务器或 NAS 跑 AstrBot／qq-bridge，设备旁的电脑运行本连接器。设备端主动连服务器的 WSS 地址，不需要家庭网络开放端口。与 DSH 界面无关，不需要安装 DSH 插件。

## 运行

需要 Node.js 24。独立包解压后，Windows 双击「启动模拟设备.bat」先检查配对；真实设备准备好后用「启动设备连接器.bat」。也可运行：

```sh
node lib/toy/remote/cli.js --simulate
node lib/toy/remote/cli.js
```

打开终端显示的本机设备控制页，默认 `http://127.0.0.1:18941`。真实模式先由用户在 Intiface／ServeUCentral 中连接单轴位移设备，默认本机服务 `ws://127.0.0.1:12345`。网页点「连接设备」，填写聊天服务器 WSS 地址和目标 QQ 私聊生成的配对码，再点「接入对话」。只显示状态、行程、速度与操作；内部标识自动生成。

「暂停设备」始终存在，立即停止并退出远程租约。再次点「接入对话」开启新租约，只执行新回复。关闭控制页后最迟 5 秒失去本地页面心跳而停止；正常关闭事件会立即请求暂停。后台页面若被浏览器节流也可能停止，需要重新接入。关闭命令窗口同样断线。不要把浏览器、电脑休眠或物理断电视作无中断播放。

本地参数与配对凭据分别保存在当前用户 `.serveu-device/motion.json` 与 `remote-token.json`，不进入模型上下文。重开自动读取，不自动连设备或接入会话；服务器进程重启需要重新配对。凭据只对原服务器地址使用。服务器不能修改本地行程、速度与暂停。

## 当前范围

复用当前播放器、29 套内置动作库、同动作源时间续播与程序限速限程。首版为桌面 Node + 本机 Buttplug v3 单轴位移；手机蓝牙、锁屏、驱动、USB／蓝牙容器透传及实体设备尚未验收。自定义轨迹管理、角色偏好、自主性完整设置尚未迁入连接器。

动作最多持续单条 holdMs（1–30 秒），同时受 10 秒连接租约约束。断线不补播；回复中的命令只有平台发送回执成功后才发往本地，不代表 QQ 已读。协议见 [PROTOCOL.md](PROTOCOL.md)。

## 开发与卸载

在活动插件根目录执行 `node src/toy/remote/build.mjs <新的输出目录>`，产生独立 ESM 包；不改 DSH `lib`。源码也可用 `node --experimental-transform-types src/toy/remote/cli.ts --simulate` 运行。

卸载时先暂停、关闭连接器，再移除独立包；需要彻底撤销时在 QQ 私聊执行「退出设备」。本地 `.serveu-device` 属用户资料，卸载默认保留，删除后需重新设置／配对。
